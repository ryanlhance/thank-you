# Ryan Hance || EPAM Continuum

A one-page hub for the EPAM Continuum team: a short note plus links to the fit map, the skills constellation, the resume, the presentation with speaker notes, and the farmer persona demo.

- `index.html` / `styles.css` — the homepage
- `resume/` — the resume HTML (self-contained, fonts embedded) plus the PDF
- `presentation/` — slide viewer; `slides/NN.jpg` are the rendered slides, `notes.json` holds speaker notes

Static site, no build step. Served by GitHub Pages from `main`.
